# Protein Function Analysis Workflow

A simple overview of how I try to understand proteins that are labelled "uncharacterized". This page explains the **method only**. No sequences, data or results are shared here.

## Steps
1. **Get the protein sequence** from a public database and note its ID.
2. **Predict the 3D structure** with AlphaFold and check how confident the prediction is.
3. **Find similar structures** using the FoldSeek web server. It runs searches and comparisons directly in your web browser, so nothing needs to be installed.
4. **Look for domains and families** with InterProScan.
5. **Compare related sequences** by aligning them in MEGA.
6. **View and compare the structures** in UCSF Chimera.
7. **Put it together** into a short guess about what the protein might do.

## What you get at the end
- A predicted structure with confidence scores
- A list of known proteins with similar structures
- The domains and families the protein belongs to
- A reasoned guess about its possible function

## Tools
AlphaFold, FoldSeek, InterProScan, MEGA, UCSF Chimera, Google Colab, Mendeley (for reading and organising papers)
